🔥 Main Difference (Point Wise)
Abstraction = hides implementation details.
Interface = defines a contract for methods.
Abstract class can have both abstract and normal methods.
Interface mainly contains abstract methods only.
Abstract class supports single inheritance.
Interface supports multiple inheritance.
